# 🎤 多 Agent 辩论系统

基于 LangGraph 的多智能体辩论系统，支持完整辩论赛流程：**立论 → 攻辩（多轮循环）→ 自我反思 → 驳论 → 总结陈词 → 评委评分**。

## ✨ 核心特性

- **多 Agent 协作**：正方/反方/评委各有独立 Agent，角色分工明确
- **五层立场防御机制**：立场铁律提示词 + 明确立场表述 + 攻辩/驳论策略指导 + 反思防反噬约束 + 评委立场坚定性评分，系统性解决大模型中立摇摆、中途倒戈问题
- **Self-Reflection 自我反思机制**（核心算法亮点）：每轮攻辩后，双方 Agent 批判自己之前的论证，找出漏洞并在下一轮修正
- **多轮攻辩循环**：基于 LangGraph 条件边实现循环，可配置 1-5 轮
- **专业评委评分**：8 个维度独立打分（含立场坚定性），输出胜负和专业点评
- **实时演示界面**：Gradio 界面，辩论过程实时展示
- **模型无关**：统一封装 OpenAI 兼容接口，支持 DeepSeek / OpenAI 等模型

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 API Key

复制 `.env.example` 为 `.env`，填入你的 API Key：

```bash
# 推荐用 DeepSeek（免费额度够开发）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
```

> 也支持 OpenAI / Qwen 等所有兼容 OpenAI 接口的模型。

### 3. 运行界面

```bash
python app.py
```

然后浏览器打开 `http://localhost:7860`

### 4. 命令行运行（无界面）

```python
from debate_agent import run_debate, format_debate_result

state = run_debate(
    topic="猫和狗谁更适合当宠物？",
    max_rounds=3,
    reflection_enabled=True,
    affirmative_stance="猫比狗更适合当宠物",   # 建议明确指定双方立场，防止立场跑偏
    negative_stance="狗比猫更适合当宠物",
)

print(format_debate_result(state))
```

> 提示：对于"选择题"辩题（如"猫和狗谁更适合当宠物"）或带贬义倾向的辩题（如"年轻人应不应该躺平"），务必传入 `affirmative_stance` / `negative_stance` 明确双方立场，否则模型可能自行脑补导致立场混淆。

## 🧠 核心算法说明

### Self-Reflection 自我反思机制

每轮攻辩结束后，双方 Agent 会暂停辩论，进行内部反思：

1. **回顾自己的所有发言**，找出逻辑漏洞和论据缺陷
2. **分析对方的所有发言**，找出自己还没有效回应的观点
3. **生成反思笔记**（仅自己可见，对方不知道）
4. **下一轮攻辩时**，将反思笔记作为输入，修正自己的论证

这个机制模拟了人类辩手在辩论间隙的复盘和策略调整，显著提升了多轮辩论的质量和深度。

### LangGraph 图编排

使用 LangGraph 的图结构（而非线性 Chain）实现辩论流程，核心优势：

- **循环支持**：攻辩阶段需要多轮循环，图结构天然支持
- **条件边**：根据当前轮数判断是继续攻辩还是进入驳论
- **状态共享**：所有 Agent 共享同一个 state dict，辩论历史完整保留
- **可观测性**：每个节点执行完都可以获取中间状态，便于调试和展示

## 📊 评测维度

评委从以下 8 个维度对双方独立打分（0-10 分）：

1. **立论深度**：论点是否有深度，定义和标准是否清晰
2. **逻辑论证**：推理是否严密，有无逻辑漏洞
3. **论据质量**：数据、案例、类比是否有力且相关
4. **反驳能力**：是否精准抓住对方漏洞并有效反驳
5. **应变能力**：面对对方攻击是否能灵活应对
6. **语言表达**：语言是否流畅、有说服力
7. **整体配合**：各阶段发言是否形成完整体系
8. **立场坚定性**：是否始终坚持己方立场，有无动摇、妥协或认同对方观点的情况
