# 📝 论文多视角审稿助手

基于 LangGraph 的多 Agent 学术论文审稿系统。上传论文 PDF/TXT/MD，4 个专业审稿 Agent 并行评审 + 主编 Agent 汇总，生成结构化的多视角审稿报告。

**适用场景**：学术论文投稿前自查、论文初稿质量评估、审稿意见参考。

## ✨ 核心特性

- **多 Agent 并行评审**：创新性、方法论、论证与证据、写作表达 4 个维度独立审稿，基于 LangGraph 并行执行
- **三层越界防护机制**：Prompt 职责边界 + 代码后处理过滤（68 个越界关键词）+ 主编维度归属校验，系统性解决 LLM 越界评审问题
- **LLM 幻觉检测**：基于论文内容的方法名称匹配，自动检测并过滤 LLM 编造的不存在的方法/模块
- **通用学科适应性**：自动识别论文类型（理工科实验类/文科实证类/理论研究类），动态调整评审重点
- **审稿意见质量控制**：基于 Jaccard 相似度的自动去重、综合评分自动计算、主要缺陷数量控制（最多 6 条）
- **结构化输出**：评分 + 主要优点 + 主要缺陷 + 修改建议清单 + 最终结论（接受/小修/大修/拒稿）
- **Gradio 交互界面**：文件上传 + 分维度 Tab 展示 + 主编报告 + 一键复制 + Markdown 导出
- **模型无关**：统一封装 OpenAI 兼容接口，支持智谱 GLM / DeepSeek / OpenAI 等模型
- **性能优化**：内存缓存机制，重复审稿同一篇论文秒级返回

## 📦 安装

### 环境要求

- Python 3.9+
- 智谱 GLM API Key（或其他 OpenAI 兼容模型的 API Key）

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/SuyeeII/paper-review-agent.git
cd paper-review-agent

# 创建虚拟环境
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的 API Key
```

### 环境变量配置

编辑 `.env` 文件：

```env
# 智谱 GLM 配置（推荐）
ZHIPU_API_KEY=your_api_key_here
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_MODEL=glm-4

# 或者使用 DeepSeek
# DEEPSEEK_API_KEY=your_api_key_here
# DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
# DEEPSEEK_MODEL=deepseek-chat

# 或者使用 OpenAI 兼容接口
# OPENAI_API_KEY=your_api_key_here
# OPENAI_BASE_URL=https://api.openai.com/v1
# OPENAI_MODEL=gpt-4
```

## 🚀 使用

### 启动服务

```bash
python app.py
```

然后浏览器打开 `http://localhost:7860`

### 使用步骤

1. 上传论文文件（支持 PDF / TXT / MD 格式）
2. 点击"开始审稿"按钮
3. 等待几分钟，系统会自动完成审稿
4. 查看分维度审稿意见和主编综合报告
5. 一键复制完整报告，或下载 Markdown 格式

## 🎯 审稿维度说明

### 1. 创新性
- 创新点是否明确？是实质创新还是增量改进？
- 相关工作对比是否充分？
- 技术贡献有多大？
- 研究方向是否有时效性？

### 2. 方法论
- 方法/算法是否合理？
- 理论推导是否严谨？
- 技术路线是否清晰？
- 方法局限性是否讨论充分？

### 3. 论证与证据
- 论证是否充分？
- 证据是否可靠？
- 实验设计是否科学？（理工科）
- 案例分析是否深入？（文科）
- 结论是否有充分支撑？

### 4. 写作表达
- 语言表达是否准确？
- 结构是否清晰？
- 术语使用是否统一？
- 文字是否简洁？

## 🛡️ 质量保障机制

### 三层越界防护
1. **Prompt 层**：每个审稿人有醒目的"负责/不负责"职责边界清单
2. **代码后处理层**：68 个越界关键词的正则过滤，覆盖主要缺陷/修改建议/扣分说明
3. **主编层**：维度归属校验，自动识别并过滤越界内容

### 幻觉检测
- 基于论文内容的方法名称匹配
- 自动检测并过滤 LLM 编造的不存在的方法/模块
- 支持 30+ 常见算法名称的检测

### 审稿意见质量控制
- 基于 Jaccard 相似度的自动去重（主要优点/主要缺陷/修改建议）
- 综合评分自动计算（解决 LLM 加法算错的问题）
- 主要缺陷数量控制（最多 6 条，按严重程度排序）
- 结构化输出（评分 + 优点 + 缺陷 + 修改建议 + 最终结论）

## 📝 注意事项

- **PDF 解析限制**：系统通过 PDF 文本提取获取论文内容，无法准确判断公式推导、图表内容、表格内容，因此不会评价这些内容
- **参考文献**：不会评价参考文献格式是否规范（PDF 解析经常丢失格式信息）
- **代码**：不会评价代码是否公开、代码质量如何（论文中通常看不到代码）
- **AI 生成内容仅供参考**：审稿意见由 AI 自动生成，最终审稿决定请以期刊/会议官方意见为准
